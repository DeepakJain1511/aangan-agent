# Aangan Studio: phone enquiry agent

Answers inbound calls (Vaani), qualifies them against Nikhil's rubric, hands qualified leads to designers on Telegram with the full context, syncs HubSpot, and shows volume and running cost on a dashboard. It never quotes a price.

Start with `docs/automation-brief.md`, then `docs/component-map.md`, `docs/architecture.md`, `docs/assumptions.md`, `docs/setup.md`, `docs/traceability.md`.

    npm install && npm test && npm run build
